# Don't Stop the Party

A hyper-casual arcade game built solo in one week for the DigiPen Summer 2025 Game Jam. 1st place winner.

Keep the party going -- dodge and fight off enemies while the crowd, lights, and confetti keep the energy up.

## Built with

- C++
- raylib (https://www.raylib.com/)

## Controls

- W / S -- navigate menus
- A / D -- move
- Enter / Space -- confirm & act
- R -- restart
